【GitHubへの反映】
1. このZIPを解凍します。
2. 中の zamajan-online フォルダーの内容を、GitHub Desktopで管理している既存の
   kakatomaru-cloud/zamajan-online リポジトリ内の同名フォルダーに上書きコピーします。
3. GitHub Desktopで Commit → Push してください。
4. Renderの自動デプロイが Live になった後、新規ルームを作って試してください。

【オンライン版で追加した内容】
- ローカル版と同じ新アイテム20種類（旧20種類を全面入れ替え）
- スコアスティール：価格8,000点、相手から3,000点を自分に移す
- 全面透視、リーチ強奪、伝説の三牌、大革命、金縛り、OJ万歳、mana2 だよ、ザマン祭など
- 第2局以降、最下位が1人または同点2人の場合に、各自が好きなアイテム1回を無料で使える権利を付与。
  最下位同点が3人以上なら付与しない。
- 最大使用数：部屋作成時に1〜3回/局を選択（初期値1回）。
- OJ万歳・mana2 だよ：発動演出・チャット宣言なし。効果中はスコアボード横に秘密装備表示。
- 継続効果アイコンを各プレイヤーのスコア欄に表示（使用者／残り手番）。
- 全面透視：発動した本人に限り、他の3人の手牌を牌画像で表示。
- 山の秘宝：山の上5枚と、戻す自分の牌をプルダウンで選択。
- 卓背景：部屋作成画面からランダム（初期値）または5種類から選択。
  部屋内の参加者全員に同じ背景を表示し、局をまたいでも同じ背景を使用。
- 元の牌画像・役・GitHub設定JSON書き出し機能も保持。
