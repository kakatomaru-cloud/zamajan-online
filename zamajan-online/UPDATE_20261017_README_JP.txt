ザマじゃん ONLINE 統合修正版 2026-10-17

変更内容
1. 新アイテム20種類の価格を4,000〜6,000点に変更（スコアスティール 6,000点／奪う点数 3,000点は維持）。
2. 役候補の警告は、現在の手牌と山の残り牌で成立可能な登録役がある場合のみ表示。
   山に必要牌が1枚も残っておらず完成不能な役は、候補から除外。
3. 秘密アイテム「OJ万歳」「mana2だよ」は宣言、ログ、得点欄の効果履歴に表示しない。
   あがり時のボーナス／ペナルティ計算は維持。
4. 部屋番号は同じブラウザーのタブ内では再利用。いったんタブ／ブラウザーを閉じて
   新しく開くと、新しい番号を発行する（ブラウザーの復元機能の挙動により例外あり）。
   使用中の部屋を別の部屋で上書きしない。
5. 卓壁紙6種類（ヴィーナスの誕生風を含む）と強力アイテム20種類を維持。
6. 上記の価格、秘密アイテム、役候補表示の修正をローカル版にも反映。

GitHub Desktopでの更新手順
ZIPを解凍し、zamajan-onlineフォルダーの中身を、既存の同名フォルダーに上書き。
GitHub DesktopでCommit to main → Push origin。Renderのデプロイ完了後、
ブラウザーでオンライン版を更新して新規対戦部屋を作ってください。
