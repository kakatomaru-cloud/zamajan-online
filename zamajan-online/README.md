# ザマじゃん ONLINE — 統合更新版

## GitHubへのアップロード

このZIPの `zamajan-online/` フォルダーの**中身**を、GitHubリポジトリ内の既存の `zamajan-online/` フォルダーへ同じ構成でアップロードしてください。ZIPファイルそのものをアップロードしないでください。二重フォルダーにしないでください。

```
zamajan-online/ （GitHubリポジトリ内）
├── package.json
├── server.js
├── README.md
└── public/
    ├── online.html
    ├── zamajan.html
    ├── title-art.jpg
    ├── table-art.jpg
    └── zamajan-bgm.mp3
```

GitHubのWebアップロードではフォルダーごとの置換が難しい場合があります。既存の同名ファイルが適切な階層で更新されたか、Commit changes後に確認してください。

## Render設定

- Language: Node
- Root Directory: `zamajan-online`
- Build Command: `npm install`
- Start Command: `npm start`

## 操作

- `/online.html` からルーム作成／参加
- 「部屋から退出してタイトルに戻る」で退出し、再接続情報を削除
- 対戦中の退出は手牌・点数・リーチを維持してCPUへ引き継ぎ
- ブラウザの保存済み牌・役設定はIndexedDBに保存。JSONバックアップを定期的に書き出してください
- 設定は部屋主のブラウザに保存されます。Renderの再起動後にルーム状態は保持されません

## オフライン版との違い

オフライン版の背景・牌画像・BGM・卓上配置・ツモ強調・リーチ／結果表示をできる限り反映していますが、ネット対戦用の操作や表示、ゲーム進行の内部処理は別実装です。完全なピクセル一致・全演出一致は保証しません。ブラウザでの複数端末検証が必要です。

## 他の端末への牌画像共有（今回の更新）

- 部屋主が読み込んだ設定JSON内の牌画像（data:image/png/jpeg/webp;base64）を、部屋作成時にサーバーへ送信します。
- サーバーは部屋の設定として画像を保持し、参加者全員に配信します。参加者側の設定JSON読み込みは不要です。
- 大きな画像は部屋主のブラウザで最大480pxに縮小してから送信します。部屋の待機画面に「共有中の牌画像：○種類」と表示されます。
- 設定JSONは部屋主のブラウザに保存されますが、ブラウザデータ削除に備えてJSONバックアップを保管してください。
- 部屋とその画像はサーバーメモリ上に保持されるため、Render再起動時に消えます。部屋主の保存済み設定から部屋を作り直せば再配信できます。
- 外部URLのみの画像は配信対象外です。オフライン版から設定JSONを書き出し、オンライン版に読み込んでください。
