# ザマじゃん ONLINE — 全ファイル更新パッケージ

## GitHubへのアップロード

このZIPの `zamajan-online` フォルダーの**中身**（`public` フォルダー、`server.js`、`package.json`、`README.md`）を、GitHubの既存 `zamajan-online/zamajan-online/` に同じ構造でアップロードして上書きしてください。ZIPそのものはアップロードしません。

RenderのRoot Directoryは `zamajan-online`、Build Commandは `npm install`、Start Commandは `npm start` です。デプロイがLiveになったらブラウザでCtrl+F5を押してください。

## 退出・切断時

対戦中の「部屋から退出」は手牌・点数・リーチ・捨て牌を変更せずにその席をCPUに変更します。部屋主が対戦中に退出した場合は、残った人間プレイヤーへ部屋主権限を引き継ぎます。待機中の部屋主退出は部屋を閉じます。通信切断後20秒以内に再接続すれば復帰し、20秒を超えるとCPUが引き継ぎます。CPUへの引継ぎ後は元の席への復帰はできません。

## 牌画像・役設定

JSONインポート時にブラウザのIndexedDBに保存し、再起動・退出・新しい対戦後も利用します。「現在の牌・役設定をバックアップ」でJSONを書き出してください。サイトデータ削除、別端末、別ブラウザ、プライベートモードでは自動移行しません。オンラインサーバー側に恒久保存されるものではありません。画像1枚が約700KB以上のものはサーバーの制限により配信されません。

## 既知の差異

オフライン版のHTMLも同梱していますが、オンライン対戦画面は別実装です。レイアウト・背景・BGM・牌表示は移植済みでも、オフライン版の全演出・詳細ルール・設定編集UIまで完全一致ではありません。オフライン版で牌画像を編集し、JSONをオンライン版に読み込む運用です。

## ローカル起動

`npm install` → `npm start` → `http://localhost:3000/online.html`
