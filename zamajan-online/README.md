# ザマじゃん ONLINE

Node.js 18以上で動作する4人対戦版です。最新の `public/zamajan.html` はオフライン版として残し、タイトルの「ネット対戦」からオンライン版へ移動できます。

## ローカル起動

```bash
npm install
npm start
```

`http://localhost:3000/online.html` を開いてください。

## インターネット公開（Render の例）

1. このフォルダを GitHub リポジトリにアップロードします。
2. Render で **New > Web Service**、リポジトリを指定します。
3. Build Command は `npm install`、Start Command は `npm start` を指定します。
4. デプロイ後、`https://発行されたURL/online.html` を友達に共有します。

## 動作仕様

- 6桁の部屋番号、4人まで、空席はCPUで補充
- サーバー側で牌山・手牌・あがり・得点・局数を管理し、各接続に本人の手牌だけを配信
- 5秒で自動ツモ、15秒で自動捨て牌、リーチ・ロン・ツモ自動判定
- 部屋主のブラウザに保存された牌画像・役設定を部屋に適用（画像はサイズ制限あり）
- 接続切断時は同じブラウザから再接続可能（部屋はサーバー再起動で消去）

**制限事項:** サーバーはメモリ内保存です。サーバー再起動で部屋と進行状況は消えます。CPUは簡易AIです。BGM・高度な演出はオフライン版と同等ではありません。オンライン版のブラウザ実機テストは未実施です。

## 注意
このZIPは公開サーバー用のプログラム一式です。HTMLをダブルクリックするだけではオンライン対戦できません。Renderなどで起動してください。無料枠のスリープやサーバー再起動でルームが消えることがあります。
